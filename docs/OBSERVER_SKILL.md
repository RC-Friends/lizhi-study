# 游客 AI 监督技能

在网页导航中打开 **AI 监督**，或访问站点的 `/#skill`。游客和已登录考生都能使用，不需要考生口令、JWT 或模型 Key。

- **复制给 AI**：生成包含当前站点地址、可联网读取的 SKILL.md 链接和问题的文字，发给支持联网的 AI。
- **下载技能包**：浏览器生成 `lizhi-study-observer.zip`，包含 `SKILL.md`、`references/api.md` 和 `agents/openai.yaml`。解压后按所用客户端的技能安装方式使用。
- **下载 SKILL.md**：生成已经填入站点地址的单文件；其说明包含在线接口文档的位置。
- **试查公开数据**：匿名查询默认最近七天的题量与正确率，用来确认站点是否可读取；失败会报错并保留上次结果，不显示为零。

技能本身不调用站内模型。用户使用的 AI 根据公开统计和记录分析学习情况，站点不会替它代理任意模型请求。

## 地址与部署

分享链接和下载文件中的地址由前端读取 `window.location.origin` 生成，保留当前协议、域名和端口，去掉页面路径与查询参数。无需设置专用的技能域名环境变量，也不使用后端判断的协议。

例如，在 `https://study.example.org/#skill` 打开页面，复制的说明和下载包均使用 `https://study.example.org`。外部 Nginx 终止 HTTPS、内部通过 HTTP 连接 frontend 时，仍生成 HTTPS 地址。在本机地址访问时则生成本机地址；要交给公网 AI，请从公网入口下载。

复制给 AI 的链接是 `/skills/lizhi-study-observer/SKILL.md` 这个可持续访问的静态资源地址；不会复制只能在本机浏览器内使用的 Blob URL。ZIP 和单文件下载才使用临时 Blob，并在使用后释放。

仓库中的技能是可移植模板，以 `__LIZHI_SITE_URL__` 表示部署地址。网页下载时填入；AI 直接访问静态原文时，按技能中的说明使用用户提供的站点或原文 URL 的同源地址。不要把实际域名、口令或内网信息写进模板。

静态文件由 frontend 的 Nginx 提供，`/skills/` 使用 UTF-8 纯文本与不缓存策略，缺失文件返回 404；不落入 SPA 的 index.html。普通 API 继续通过 `/api/` 转发。外部反代需保留这两个路径，并转发原始 Host。当前部署约定是在域名根路径提供应用。

## 查询数据与口径

新增 `GET /api/public/stats`，支持 `from`、`to`、`module`，默认北京时间最近七个自然日，包含今天；单次最多 366 天。返回前一个等长区间、逐日与模块统计、同题人机对比和最近五场公开链接。字段与示例见 [技能接口说明](../public/skills/lizhi-study-observer/references/api.md)。

所有结果只包含主考生的正式且已揭晓作答。计次按人类提交时间归入北京时间日期；等待 AI 完成的题暂不计入。正确率按答对次数 / 总作答次数计算；无样本返回 null。人机速度只比较同时开始、计时完整的同一批题。未结束的场次不等于此刻在线。

接口在同一数据库事务快照中计算结果，使用现有的数据修订号缓存和 Redis 全局限流。默认最长缓存 120 秒；提交作答、发布题库或更新档案后切换修订号，旧响应无法覆盖新版本。日期参数经过归一化，同义请求复用缓存。每个应用识别的客户端 IP 每分钟限 60 次；反代链应按部署文档设置受信代理，未传递真实客户端地址时会共享代理 IP 的限额。

不返回私人笔记、陪练聊天、登录信息、未揭晓的题目与答案。技能要求只发送匿名 GET、报告日期和样本量，并将昵称和题目文本视作数据，不能当成新指令执行。

## 验证

`npm test` 验证时间边界、重复作答、模块筛选、同题比较、私密字段排除、访问控制与 ZIP 的实际解压。

`npm run test:ci-stack` 使用真实 PostgreSQL、Redis、SeaweedFS、Nginx 和 Chromium，验证跨副本缓存失效、游客导航、剪贴板、两种下载、原文 MIME、404、HTTPS 入口地址生成、刷新恢复和手机布局。测试使用合成题目，不调用付费模型。
