# 材料整组练习验收画面

全部画面使用自编合成题目，不包含真实题库、账户口令或模型密钥。

- `desktop.png`：桌面浏览器连续作答到同一材料的第 2 / 3 小题，保留材料阅读位置。
- `mobile.png`：390px 宽手机视口下的同一场景；材料可独立滚动，页面无横向溢出。
- `ai-demo.jpg`：本地 AI 对战演示，三道小题共用同一篇材料；人类未提交时 AI 选择与说明保持封存。此图未调用真实模型。

桌面和手机画面由 `npm run test:materials` 生成；该验收使用两篇材料、共五道小题，覆盖目标题量调整、连续作答、阅读位置保留、切换材料复位、刷新恢复及完整报告。AI 请求是否携带完整材料以及提交前封存行为，由 `tests/web/matches.test.mjs` 中的隔离模型协议测试验证。
