# 站点管理

系统保留单考生模式，不提供注册、邀请码或用户管理。游客查看公开学习记录，考生做题、整理资料和维护个人学习设置，超级管理员维护模型、资料库与题库。

## 登录

在服务端环境文件中配置两个不同的口令：

```dotenv
SITE_PASSWORD=<考生口令，至少8个字符>
SUPERADMIN_PASSWORD=<独立管理员口令，至少12个字符>
JWT_SECRET=<独立随机签名密钥，至少32字节>
```

`npm run stack:prepare` 会自动生成这些值，写入权限为 0600 的 `.env.stack`。既有部署可以只补充 `SUPERADMIN_PASSWORD`；留空时管理员登录关闭，原考生登录和 JWT 仍然有效。

点击网页页脚「站点管理」，或打开 `/#admin`，输入超级管理员口令。登录状态保存在浏览器本地，刷新可以恢复。同一浏览器一次使用一个身份；退出管理后可重新以考生身份登录。

管理员 JWT 使用独立的角色、主体和受众。考生 JWT 不能读取或修改模型配置、导入题库或访问管理状态；管理员也不会生成第二份考生档案。修改某个身份的启动口令只使该身份的旧 JWT 失效，修改 `JWT_SECRET` 则使两种身份的会话全部失效。

## 首次初始化模型配置

数据库没有模型配置时，后端在初始化事务中把 `LLM_*`、`JEV_*`、`VISION_*`、`EMBEDDING_*` 和 `RERANK_*` 导入 `study_ai_config`。已有配置时只校验并使用数据库值，不再合并环境变量；多个副本同时启动也只初始化一次。既有版本首次增加 Embedding 或 Rerank 时，只导入对应新提供方的启动值，不改写已有模型设置；未提供启动值则默认为停用、无密钥。

之后通过管理面板维护：

- **通用 LLM**：人机对战、小栗陪练、知识库出题，以及是否允许图片输入。
- **JEV 决策模型**：JEV 对战的地址、密钥、模型与超时。
- **JEV 视觉助手**：图片转写服务，可独立启停和配置。
- **Embedding 检索**：知识库语义检索的地址、独立密钥、模型、向量维度与相关度阈值；支持连接测试、查看索引进度、重试失败片段和试查资料。
- **Rerank 重排**：候选片段的二次排序，支持独立启停、连接测试、候选数与相关度阈值。可单独配合关键词检索，也可搭配 Embedding。两者支持明确关闭 API Key 认证，适配无需密钥的模型服务。
- **高级参数**：请求超时、输出额度、图题额度、手动重试额度、思考模式及推理强度。

保存后，所有后端的新请求和新执行任务读取最新配置；已经发出的模型请求继续使用其原配置。配置变更推进共享修订号，考生页面也会刷新模型可用状态，无需重启。

模型密钥仅保存于后端持久化配置，接口只返回是否已设置和末四位。留空保留现有密钥，勾选「清除现有密钥」才会删除。更换服务地址时必须同时提供该服务的新密钥或清除旧密钥，防止旧凭证发往新地址。清空或停用模型后，系统不会回退使用旧环境变量中的密钥。

模型配置在 PostgreSQL 备份范围内，应与学习记录一起备份。文件模式仅供本地开发，使用运行目录旁的 `ai-config.json` 保存，语义同样为首次导入；生产模式必须使用 PostgreSQL 和 Redis。

基础设施连接、两个身份的口令和 JWT 签名密钥仍是启动配置，不会通过网页回显。模型面板不是任意请求转发器，只提供配置和固定的连接测试。

## 资料与题库

考生与管理员维护同一份资料库，所有资料继续归属现有 `primary` 考生，没有账号迁移。支持 Markdown、TXT、文字 PDF 和 Word；图片可保存，但尚不参与出题。新资料上传限额包含 base64 编码后的体积，Nginx 与后端限制保持一致。

题库导入面板可以下载标准 JSON 范例与 Schema、校验 JSON，并上传由导入工具生成的完整资源目录。发布使用已有的版本化对象存储流程，通过完整校验后在线启用；不会替换历史记录引用的原题。详见 [题库导入说明](QUESTION_IMPORT.md)。

网页使用超级管理员 JWT 调用导入 API，不需要把命令行管理令牌或对象存储密钥复制到浏览器。发布仍需后端的 `QUESTION_IMPORT_S3_ACCESS_KEY_ID` 和 `QUESTION_IMPORT_S3_SECRET_ACCESS_KEY`；未配置时，面板显示原因，格式校验仍可用。

知识库出题支持 BM25、可选 Embedding 和可选 Rerank，配置、索引与四种组合的回退说明见 [知识库检索说明](KNOWLEDGE_RETRIEVAL.md)。当前 AI 出题为临时巩固练习，答案由模型生成，暂不计入正式学习统计；原题库练习、错题本、公开监督及 AI 监督技能保持原来的记录口径。

## 接口

| 接口 | 身份与用途 |
| --- | --- |
| `POST /api/login` | `{ "role": "admin", "password": "..." }` 登录管理员；省略角色仍为考生 |
| `GET /api/session` | 返回当前身份，不回显口令 |
| `GET /api/admin/status` | 管理员查看服务、题库与资料统计 |
| `GET /api/ai/config` | 管理员读取五个模型的脱敏配置和修订号 |
| `PUT /api/ai/config` | 管理员修改 `provider: llm / jev / vision / embedding / rerank`；带 `revision` 防止覆盖其他页面的新设置 |
| `POST /api/ai/config/test` | 管理员测试所选模型，不保存测试值 |
| `/api/admin/question-bank/*` | 超级管理员 JWT 或原独立导入令牌；考生禁止访问 |
| `GET /api/admin/rag/status` | 管理员查看向量索引统计 |
| `POST /api/admin/rag/reindex` | 管理员补齐与重试索引；`{ "force": true }` 重新生成所有片段 |
| `GET /api/kb/search?q=...` | 考生或管理员检索可访问资料，返回片段、检索方式与回退原因 |

修改配置示例：

```json
{
  "provider": "llm",
  "revision": "GET 接口返回的修订号",
  "baseUrl": "https://api.example.com/v1",
  "apiKey": "新服务的密钥",
  "model": "vision-model",
  "enabled": true,
  "vision": true,
  "timeout": 180000
}
```
