# 公务员备考 App（Civil Service Exam Prep）

基于 **Expo (React Native) + SQLite** 的公务员考试行测刷题应用，数据完全本地存储，离线可用。核心特色是**「同一易错坑反复刷」的同坑强化训练**。

## 功能特性

| 模块 | 说明 |
| --- | --- |
| 模块刷题 | 言语理解 / 数量关系 / 判断推理 / 资料分析 / 常识判断 五大模块选题，支持**图表题**（表格/柱状/折线） |
| **模拟考试** | 选模块/题量/时限，计时答题、自动交卷、成绩与错题复盘 |
| **远程题库** | 约 5000 道国考+各省历年行测真题**已内置打包**，离线可用；联网时按镜像源（GitHub/jsDelivr/代理）增量更新，设置页可手动同步 |
| **同坑强化** | 每道题标注易错「坑点」（按模块分组、默认折叠），答错后提示一键连刷同坑题，连续答对判定掌握 |
| **做题回看** | 刷题页支持「上一题/下一题」来回查看，保留每题作答与解析 |
| **做题画笔** | 在题目/图表上划线标记，工具栏在右上角，画笔/橡皮擦/清空/完成一键切换 |
| **跳过未答** | 未选择时底部同样有「下一题」按钮，点击跳过此题不记作答 |
| **同坑小轮刷** | 答错后一键进入同坑强化（每轮 ≤10 题），返回回到原题原位，可反复「再刷一轮」 |
| **成语板块** | 隶属言语理解：单个成语反复练 + 相近成语辨析（67 题） |
| **速算板块** | 隶属资料分析：尾数/首数/特征数字/放缩/凑整等速算技巧专项（40 题） |
| **AI 答疑** | 答完题解析处一键进入 AI 对话，讲解思路与避坑方法（支持 Markdown 排版） |
| 错题本 | 错题自动入册，按坑点分组，一键重刷 |
| SRS 间隔重复 | 错题按 L1→L5（1/3/7/15/30 天）间隔复习，答对升级、答错归零 |
| 收藏整理 | 收藏题自动分类（模块/坑/题源），自定义收藏夹 + 自定义标签 |
| 数据统计 | 总正确率、模块正确率、**薄弱坑点排行**、最近练习记录 |
| **设置** | 选择 AI 服务商（DeepSeek/OpenAI/通义千问/Kimi/智谱/自定义）、Base URL、**模型下拉选择**与 API Key |

## 技术栈

- **Expo SDK 54 / React Native 0.81 / TypeScript**
- **expo-sqlite**（本地数据库，WAL 模式）
- **react-native-safe-area-context**（适配全面屏/状态栏）
- **zod**（题库数据校验）
- **Node 工具脚本**（tsx）：题库导入、AI 出题

## 环境要求

- Node.js ≥ 20
- 手机安装 **Expo Go（SDK 54 版本）**，与电脑同一 Wi-Fi

## 快速开始

```bash
npm install          # 安装依赖
npm start            # 启动 Expo，手机 Expo Go 扫码
```

首次启动会自动建表并灌入种子题库（**约 5400 题**：自建 + 已复核 AI 题 + 打包内置的 5000 道真题），完全离线可用；联网时后台按镜像源（GitHub raw → jsDelivr → 代理）拉取最新真题增量合并。

## 常用命令

| 命令 | 说明 |
| --- | --- |
| `npm start` | 启动 Expo 开发服务器 |
| `npm run typecheck` | 全量 TS 类型检查（App + 工具脚本） |
| `npm run import:quiz` | 校验/导入题库：`-- <题目.json\|题目.xlsx>`（Excel 需含"题干/答案/解析"列，可带 选项A-E/模块/坑点/年份/省份/难度），`--write <输出>` |
| `npm run import:bank` | 从 `saduck` 粉笔真题 JSON 生成远程题库 `questions/questions.json`（`--cap 每坑上限 --target 目标题量`） |
| `npm run gen:questions` | 用 DeepSeek 生成题目（需 `.env` 配 `DEEPSEEK_API_KEY`） |
| `npm run gen:batch` | 按模块+坑点批量生成（`--module <模块>` `--count <每题数>`） |
| `npm run review:questions` | AI 题复核：`--list` 列表 → `--approve 0,2,5` / `--approve-all` 标记 → `--export` 写入 App 种子库 |
| `npm run check:version` | 提交前版本一致性检查（自动运行于 pre-commit） |
| `npm run version:patch` | 版本号 +0.0.1（`minor`/`major` 同理，不自动打 tag） |

## 题源管线

1. **公开真题 + 自建**：`tools/import-quiz.ts` 读取 JSON 或 **Excel**（列名：题干 / 答案 / 解析 / 选项A–E / 模块 / 坑点 / 年份 / 省份 / 难度）校验并统计；种子题库为自建模拟题。
2. **远程真题库**：`tools/import-bank.ts` 从 `saduck`（粉笔真题 JSON 快照）清洗去重、按坑点标签均衡抽样生成 `questions/questions.json`（含解析、知识点坑点标签与题图 URL）；App 启动从 GitHub raw 下载并幂等合并。
3. **AI 生成**：`tools/gen-questions.ts` 调用 DeepSeek 按「模块 + 坑点」出题，zod 校验后落盘为 `reviewed=false`。
4. **人工复核**：`npm run review:questions -- --list` 查看待复核题 → `--approve 0,2,5` 标记通过 → `--export` 写入 `src/data/seed/aiSeed.ts`。
5. **App 自动合并**：App 每次启动会把种子题（自建 + 已复核 AI 题 + 本地缓存的远程真题）幂等合并进本地库，**新题无需清库**；未复核题永不进入刷题。
6. **抓取**（预留，默认关闭）：培训机构题库受版权保护，默认不启用。

## 目录结构

```
App.tsx                  # 应用入口 + 页面导航
questions/questions.json # 远程真题库（约 5000 题，App 启动自动下载合并）
src/
  db/                    # SQLite schema、初始化、类型化查询仓库
  data/seed/             # 种子题库（自建 + 已复核 AI 题，App 启动时合并）
  data/generated/        # AI 生成待复核题（reviewed=false）
  screens/               # 首页 / 刷题 / 错题本 / 收藏 / 详情 / 统计
  components/            # 通用组件（题图、图表、AI 答疑、收藏夹选择等）
  services/              # 远程题库同步
  types/                 # 题目类型 + zod 校验
  utils/
tools/                   # 数据管线脚本（导入 / 远程题库 / AI 出题 / 复核 / 版本检查）
githooks/                # git 钩子（提交前自动检查）
```

## 版本管理流程

- 版本号以 `package.json` 的 `version` 为唯一来源。
- **每次提交前**：
  1. 按变更大小执行 `npm run version:patch`（或 `minor` / `major`）升级版本号；
  2. 在 `CHANGELOG.md` 顶部新增对应版本条目（`## x.y.z`）；
  3. 更新 `README.md`（功能变更时同步「功能特性」，版本历史追加一行）；
  4. `git commit` 时 pre-commit 钩子会自动运行 `npm run check:version`，校验版本号已同步到 CHANGELOG 与 README，不一致则阻止提交（可用 `--no-verify` 跳过，不建议）。

初始化钩子路径（一次性，需在克隆后执行）：

```bash
git config core.hooksPath githooks
```

- 种子题为自建模拟题；远程真题库数据来源为公开的粉笔真题快照（`mpbfx/gongkao` 仓库，AGPL-3.0），仅作个人学习使用，题面/解析版权归原作者所有，不用于商业用途。
- `.env` 不入库；DeepSeek API Key 供命令行工具（批量出题）使用。
- **App 内 AI 答疑的服务商、模型与 Key 在「设置」页自行配置**，仅保存在本机 SQLite，不打包进安装包、不上传。
